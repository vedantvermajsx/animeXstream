#  AnimeXtream

AnimeXtream is a modern, high-performance anime discovery and tracking platform built with React and Tailwind CSS. It leverages the Jikan API (MyAnimeList) to provide a seamless experience for exploring thousands of anime titles, reading detailed reviews, and tracking your favorites.

![React](https://img.shields.io/badge/React-18.3.1-61DAFB?logo=react)

##  Features

- ** Cinematic UI/UX**: A modern, dark-themed interface designed for an immersive anime browsing experience.
- ** Comprehensive Search**: Find any anime using a powerful search engine powered by the Jikan API.
- ** Genre Discovery**: Browse anime by specific genres and themes with an intuitive tag-based filtering system.
- ** Favorites System**: Save your favorite anime locally to keep track of what you love.
- ** Rich Reviews**: Read detailed user reviews with reaction stats, spoiler warnings, and expandable content.
- ** Fully Responsive**: Optimized for all devices, from desktop monitors to mobile screens.
- ** Video Player**: Integrated trailer and episode viewing experience.
- ** Performance Optimized**: Features lazy loading, skeleton screens, and efficient state management.

##  Tech Stack

- **Frontend**: [React](https://reactjs.org/) (Hooks, Router, Suspense)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Data Fetching**: [Axios](https://axios-http.com/)
- **API**: [Jikan API](https://jikan.moe/) (Unofficial MyAnimeList API)
- **Build Tool**: [Vite](https://vitejs.dev/)

##  Getting Started

### Prerequisites

- Node.js (v16.0.0 or higher)
- npm or yarn

### Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/creepJxVedant/animeXstream.git
   cd animeXstream
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start the development server**:
   ```bash
   npm run dev
   ```

4. **Build for production**:
   ```bash
   npm run build
   ```
